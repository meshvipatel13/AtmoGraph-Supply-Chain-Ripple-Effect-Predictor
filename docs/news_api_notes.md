# NewsAPI Research

## Purpose

Collect real-time news related to supply chain disruptions.

## Endpoint

/v2/everything

## Important Search Keywords

- supply chain
- logistics
- port strike
- shipping delay
- factory shutdown
- semiconductor shortage
- cargo
- maritime
- trade ban

## Important Fields

- title
- description
- content
- source
- publishedAt
- url

## Output Format

JSON

## Why are we using NewsAPI?

To provide real-world news as input to our NLP pipeline.
